# Local triage roles

Categories: bug, enhancement. States: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. Store roles in the local issue's metadata; this example creates no remote labels.

Incoming raw reports use triage. Tickets produced by to-tickets are already agent-ready and keep their blockers/approved scope. A label never grants production, data, credential or publication rights.
