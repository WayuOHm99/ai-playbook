# Prompt library (ภาษาไทย)

คลัง prompt สำหรับคัดลอกไปวางใน Claude Code และ Codex ทุกอันมีบรรทัด "ใช้เมื่อ" และ "ได้อะไร" อยู่เหนือกล่อง ช่อง `<...>` คือที่ที่ต้องกรอกเอง ทุกอันระบุ เป้าหมาย บริบท ขอบเขต (ทำ / ไม่ทำ) เสร็จเมื่อ วิธีตรวจ และรูปแบบรายงาน และสั่งให้ agent เห็นต่างและชี้ความเสี่ยงที่คุณอาจมองข้าม

ตั้งค่าครั้งเดียว: ตั้งโมเดลและ effort ที่เครื่องมือตอนเริ่ม session (ไม่ต้องเขียน "คิดให้หนักๆ" ใน prompt) ไม่ใส่ข้อมูลผู้ป่วยจริง รหัสผ่าน หรือ API key ในแชท

## ลำดับงานโดยรวม (ถ้าไม่มั่นใจว่าอยู่ขั้นไหน ให้ใช้ 02-B)

ไอเดีย (01-A, 01-B) -> ระดับงานและ stack (01-C, 01-D, 01-E) -> spec และ tickets (`/to-spec`, `/to-tickets`) -> ทำทีละ ticket (02-A, 02-C) -> ตรวจ (05-A ถึง 05-D) -> ปล่อยและส่งมอบ (07-C, 07-D) โดยแทรก 08-A ถึง 08-D ก่อนจุดตัดสินใจใหญ่ และ 04-D ทุกครั้งที่นึกอะไรออกกลางงาน

## 5 กฎเขียน prompt เอง

ที่มา: research/06-prompting.md

1. **ใส่วิธีตรวจและเกณฑ์เสร็จเสมอ** ปิดท้ายด้วยคำสั่งที่รันได้ (เช่น `npm run verify`) และสั่งให้แสดงผลจริง ถ้ายังไม่มีเทส ให้ขอเขียนเทสที่แดงก่อน วิธีตรวจคือสิ่งที่ช่วยได้มากที่สุด
2. **บอกผลลัพธ์ ขอบเขต (ทำ / ไม่ทำ) และเหตุผล** ไม่ต้องไล่ทีละขั้น สิ่งที่นอกขอบเขตให้ agent จดไว้ใน BACKLOG.md หรือหัวข้อ "พบเพิ่ม" ไม่ใช่ลงมือทำเอง ใช้คำกำกวมอย่าง "ปรับให้ดี" หรือ "ระดับโลก" ไม่ได้ ต้องแปลงเป็นเกณฑ์ที่ตรวจได้
3. **หนึ่งงานต่อหนึ่ง session** ข้อความยาวที่มีหลายเรื่องปนกันให้จัดแยกก่อน (01-B) แล้ว `/clear` ระหว่างงานที่ไม่เกี่ยวกัน ถ้าแก้เรื่องเดิมเกิน 2 รอบให้เริ่มใหม่พร้อมสิ่งที่เรียนรู้
4. **ใช้ภาษาคนละส่วนให้ถูกที่** โครงสร้างและกติกาถาวรเป็นอังกฤษ บทสนทนาและเหตุผลเป็นไทยได้ โค้ด path error ชื่อตัวแปร คัดลอกตามต้นฉบับ ระบุภาษาตอบ และข้อความหน้าจอภาษาไทยให้ระบุเป็นตัวอักษรตรงๆ ให้ agent ไม่แต่งเอง
5. **ขอให้เห็นต่าง ตรวจแยก และใช้ประโยคสงบ** เขียนว่า "ถ้าเห็นว่าผิดให้บอกหนึ่งประโยคแล้วทำต่อ" หรือใช้ไฟล์ 08 เมื่ออยากได้คำค้านเต็มๆ ให้ผู้ตรวจเป็น session ใหม่ ส่งรายงานทุกข้อที่เข้าเกณฑ์แล้วคุณกรองเอง ห้ามตะโกนด้วยตัวพิมพ์ใหญ่หรือ "ห้ามเด็ดขาด" ทุกประโยค ให้ใส่เหตุผลแทน

## ประโยคที่เอาไปต่อท้าย prompt ไหนก็ได้

```text
ถ้าเห็นว่าคำสั่งของฉันผิดหรือมีวิธีที่ดีกว่า ให้บอกหนึ่งประโยคแล้วทำต่อตามที่สั่ง (ยกเว้นเรื่องข้อมูลผู้ป่วย สิทธิ์ หรือตัวเลขการเงิน ให้หยุดถามก่อน)
ท้ายรายงานให้มีหัวข้อ "ความเสี่ยงที่คุณไม่ได้ถาม แต่ฉันควรรู้" ห้ามเว้นว่าง ถ้าไม่พบให้บอกว่าตรวจอะไรไปแล้ว
ทำเฉพาะที่ขอ สิ่งอื่นที่เห็นให้จดไว้ อย่าทำเอง ห้ามสร้างเทสหรือเอกสารเพิ่มนอกที่ระบุ ลบไฟล์ชั่วคราวที่สร้างเอง
```
