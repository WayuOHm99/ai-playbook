# Triage: จัด issue ที่เข้ามาให้พร้อมตัดสินใจ

ทางเข้าหลักคือ [Matt `ask-matt`](../skills/engineering/ask-matt/SKILL.md) ใช้ [Matt `triage`](../skills/engineering/triage/SKILL.md) เมื่อมี bug report หรือ feature request ดิบจากผู้อื่น สกิลทำงานตาม issue roles ที่โปรเจกต์ตั้งไว้ใน `docs/agents/triage-labels.md` ส่วน tickets ที่ `to-tickets` สร้างพร้อมทำแล้ว ไม่ต้อง triage ซ้ำ

ตาราง P0–P7 ด้านล่างเป็นข้อมูลช่วยอ่านความเสี่ยงและขอบเขตตาม [core](../instructions/core.md) ไม่ได้ตั้ง router อีกตัว

| ระดับ | สถานการณ์ | การกระทำภายในขอบเขต |
|---|---|---|
| P0 | ระบบจริงล่มต่อเนื่อง ข้อมูลหาย ข้อมูลส่วนตัวรั่ว หรือเสี่ยงข้อมูลผิดคน | วิเคราะห์ read-only และบันทึกเหตุการณ์; การเปลี่ยน production ต้องได้สิทธิ์เฉพาะ |
| P1 | บั๊กใน ticket ที่กำลังทำ | แก้ตามเกณฑ์ของ ticket ด้วย test กันพังซ้ำ |
| P2 | บั๊กในพฤติกรรมที่ส่งไปแล้ว | ทำให้เกิดซ้ำและวินิจฉัยก่อน; `implement`/`tdd` แก้เมื่ออยู่ในงานที่อนุมัติแล้ว |
| P3 | feedback ว่ายังไม่ตรง spec | เทียบเกณฑ์รับงาน แก้เป็นบั๊กในขอบเขตเดิม |
| P4 | เปลี่ยนความหมายหรือเพิ่มบริการ secret ค่าใช้จ่าย หรือข้อมูลส่วนตัวใหม่ | ร่างผลกระทบและ spec ให้ตัดสินใจก่อนลงมือส่วนที่ยังไม่ได้อนุมัติ |
| P5 | ไอเดียเพิ่มกลางงาน | จดลง `BACKLOG.md` แล้วทำ ticket เดิมต่อ |
| P6 | cleanup/debt ที่พบเอง | จดพร้อมหลักฐาน แยกจาก diff ปัจจุบัน |
| P7 | โปรเจกต์ใหม่ | `ask-matt` → `grill-with-docs`/`grill-me`; ตรวจระดับงานและ feasibility ก่อน build |

| Issue role | ความหมาย |
|---|---|
| `needs-triage` | ยังไม่ประเมิน |
| `needs-info` | ต้องได้ข้อมูลเพิ่มจากผู้รายงาน/เจ้าของระบบ |
| `ready-for-agent` | ระบุงานและหลักฐานครบ อยู่ในสิทธิ์ที่ agent ทำได้ |
| `ready-for-human` | รอการตัดสินใจหรือการกระทำที่ agent ยังไม่มีสิทธิ์ |
| `wontfix` | ตั้งใจไม่ทำ พร้อมเหตุผลที่ค้นกลับได้ |

การร่าง issue/label ทำได้ตามขอบเขต การเผยแพร่หรือเปลี่ยนสถานะยึดสิทธิ์ใน session กับกฎกลาง งานข้อมูลส่วนตัว auth migration หรือ production ไม่กลายเป็นงานอัตโนมัติเพียงเพราะมี label

`BACKLOG.md` เป็น inbox ของโปรเจกต์ ไม่ใช่ที่ขยาย ticket ปัจจุบัน เรื่องที่เลือกทำจึงย้ายไป tracker ตาม setup งานใหม่ทุกชิ้นควรมีผลลัพธ์ ขอบเขต และเกณฑ์ตรวจได้
