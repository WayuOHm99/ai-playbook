## ข้อจำกัด

- **งานเอกสาร ไม่มีโค้ดและเทสต์:** ไม่ได้ทดสอบส่วน `tdd` ของห่วงโซ่
- **ไม่มีหลักฐานว่ารัน `code-review` หรือ `review-candidate.mjs`:** PR body ไม่กล่าวถึง และไม่มี review บน GitHub ถ้ารันในเซสชันก็ไม่ได้บันทึกไว้
- **หัวข้อ PR ไม่ตรงแม่แบบของสกิล `pr`:** ใช้ "Check ที่รัน" แทน Summary / Evidence / Merge Danger จึงยืนยันไม่ได้ว่าใช้สกิล `pr` ของ playbook ขั้น "ร่างสามระดับด้วย agent ย่อย" ก็ไม่อยู่ใน `implement` ซึ่งอาจมาจากกฎของ repo เอง (repo มีสกิล `finish-issue` และ `AGENTS.md` ของตัวเอง)
- **จำนวนข้อความเป็นคำบอกของผู้ใช้:** ไม่ได้นับจากประวัติแชท
- **เกณฑ์เสร็จของ #264 ยังไม่ครบตอน merge:** #264 กำหนดว่า "ไม่มีกฎหรือเหตุผลที่หายไป (ตรวจเทียบกับ AGENTS.md เดิม)" แต่ PR ระบุเองว่าไม่ได้เทียบทีละบรรทัด และ merge ภายใน 2 นาที
