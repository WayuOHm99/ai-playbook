# คัดแยกงานใหม่: ทำเลย หรือเก็บไว้ก่อน

> ใช้ทุกครั้งที่มีบั๊ก, feedback, ไอเดีย หรือ requirement ใหม่เข้ามา ไล่จากบนลงล่าง **ข้อแรกที่ตรงคือคำตอบ**
> ที่มา: `research/01-agent-workflows.md` §2 (Matt Pocock /triage, Anthropic best practices, Kent Beck, Addy Osmani)

| ระดับ | ประเภท | ทำอะไร | ไปที่ไหน | agent ทำเองได้ไหม |
|---|---|---|---|---|
| **P0** 🔥 | ระบบจริงล่ม, ข้อมูลหาย, ข้อมูลส่วนบุคคลหรือผู้ป่วยรั่ว, เสี่ยงข้อมูลผิดคน | หยุดทุกอย่าง กู้ระบบก่อน หาสาเหตุทีหลัง | บันทึกเหตุการณ์ + ticket | วิเคราะห์และเสนอได้ **แต่คุณต้องอนุมัติทุกการแตะ production** |
| **P1** 🐞 | บั๊กในงานที่กำลังทำอยู่ตอนนี้ | แก้ใน ticket เดิม พร้อม test กันพังซ้ำ ข้อนี้ไม่นับเป็นงานบาน | ticket ปัจจุบัน | ได้ |
| **P2** 🐛 | บั๊กในสิ่งที่ส่งไปแล้ว | เขียน test ให้เกิดซ้ำก่อน แล้วเปิด ticket ตามความรุนแรง | GitHub Issue: bug | ทำให้เกิดซ้ำได้เอง แก้หลังมี ticket |
| **P3** 💬 | feedback: "ยังไม่ตรงกับที่ตกลงไว้" | ถือเป็นบั๊กเทียบกับ spec | ticket ปัจจุบันหรือถัดไป | ได้ |
| **P4** ✏️ | feedback: "อยากให้ทำงานต่างจากเดิม" | เป็นการเปลี่ยน requirement: เขียนว่าเปลี่ยนอะไร เพราะอะไร และกระทบอะไร แล้วแก้ spec | ความเห็นใน spec + ticket ใหม่ | **ไม่ได้** ต้องให้คุณตอบ yes ก่อน |
| **P5** 💡 | ไอเดียใหม่, "เพิ่มอันนี้ด้วย", "ทำให้ระดับโลก" | **ห้ามทำกลางคัน** จด 1 บรรทัดลง `BACKLOG.md` แล้วทำงานเดิมต่อ | `BACKLOG.md` | จดลง BACKLOG ได้อย่างเดียว |
| **P6** 🧹 | งานเก็บกวาดที่ agent เห็นเอง | จดพร้อมหลักฐาน ห้ามแก้ใน diff เดียวกัน | `BACKLOG.md` (tag: debt) | จดได้อย่างเดียว |
| **P7** 🚫 | agent ทำเกินที่สั่งเอง (ฟีเจอร์เพิ่ม, refactor ที่ไม่ได้ขอ) | ถอยออกหรือแยกออก บันทึกใน "ยังไม่ได้ทำ" ของรายงาน | `BACKLOG.md` | ต้องหยุด |

## BACKLOG ทำงานอย่างไร
- ใช้ไฟล์เดียวคือ `BACKLOG.md` (หรือ GitHub Issues label `needs-triage`) บรรทัดละ 1 เรื่อง: วันที่, มาจากไหน, 1 ประโยค, ประเภทที่คาดไว้
- **คัดแยกสัปดาห์ละครั้งในเวลาที่กำหนด** ไม่ใช่ทุกครั้งที่มีเรื่องเข้ามา
- เรื่องที่ตัดสินใจว่าไม่ทำ ให้บันทึกเหตุผลไว้ ครั้งหน้าที่ไอเดียเดิมกลับมา agent จะเจอคำตอบเก่าแทนที่จะเริ่มถกใหม่

## เหตุผลที่ต้องเข้มกับ P5
จากประวัติแชทของคุณ:
- หน้า login ถูกออกแบบใหม่ 6 รอบ
- RubricLens ได้ระบบที่ไม่ต้องการเพราะคำว่า "ระดับโลก"
- งานค้างใน repo ที่ยังไม่ commit ถึง 30–40 ไฟล์

ทั้งหมดเกิดจากไอเดียที่เข้ามากลางงาน (ดู `me/pitfalls.md`)
