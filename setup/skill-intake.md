# ติดตั้งสกิลของคนอื่น: checklist ก่อนติดตั้ง

> การติดตั้งสกิลหรือ plugin ของคนอื่น **นับเป็นการเพิ่ม dependency** ตามหัวข้อ Permissions ใน `instructions/core.md` (ข้อ 3 ใน `core-th.md`) agent ต้องถามคุณก่อนทุกครั้ง
> ที่มา: Anthropic "Skills for enterprise" (https://platform.claude.com/docs/en/agents-and-tools/agent-skills/enterprise, อ่านเมื่อ 2026-10-01), Snyk พบสกิลสาธารณะ 36.82% จาก 3,984 ตัวมีปัญหาความปลอดภัยอย่างน้อย 1 จุด (รายงานของผู้ขายเครื่องมือ), Trail of Bits `skills-curated` (ดู `research/10-skill-libraries-community.md`)

## ก่อนติดตั้ง: ให้ agent ตรวจ 8 ข้อแล้วรายงาน (อ่านทุกไฟล์ในโฟลเดอร์สกิล)

| # | ตรวจอะไร | ไม่ผ่านเมื่อ |
|---|---|---|
| 1 | ที่มา | repo ไม่มีเจ้าของชัดเจน ไม่มีคนใช้ ไม่มี commit ปีนี้ หรือไม่มี license |
| 2 | สคริปต์ (`scripts/`, คำสั่งใน SKILL.md) | ลบไฟล์, แก้ไฟล์นอกโปรเจกต์, ติดตั้งโปรแกรม, ใช้ `curl \| sh` |
| 3 | คำสั่งแฝงที่หลอก agent | มีข้อความสั่งให้ข้ามกฎ, ปิด hook, ไม่ต้องถามผู้ใช้, หรือซ่อนไว้ในคอมเมนต์และอักขระพิเศษ |
| 4 | การเรียกเครือข่าย | ส่งข้อมูลออกไป URL ภายนอกโดยไม่จำเป็น |
| 5 | รหัสผ่านหรือ key ที่ฝังมา | มี token, key หรือ URL ที่มีรหัสผ่าน |
| 6 | MCP server ที่ผูกมา | เปิด MCP server ของบุคคลที่สามโดยอัตโนมัติ |
| 7 | ขอบเขตไฟล์ | อ่านหรือเขียนนอกโปรเจกต์ เช่น `~/.ssh`, `.env`, ไฟล์ตั้งค่าของ shell |
| 8 | ความซ้ำซ้อน | ทำงานซ้ำกับสกิลที่มีอยู่แล้ว (ดูสกิลที่ติดตั้งจริงในหัวข้อ "สภาพเครื่องจริง" ของ `STATE.md` และ `skills/catalog.json`) หรือชื่อชนกัน |

prompt ที่ใช้สั่งได้เลย:
```
ตรวจสกิล <URL หรือ path> ตาม D:\ai-playbook\setup\skill-intake.md ทั้ง 8 ข้อ อ่านทุกไฟล์ในโฟลเดอร์ อย่าติดตั้ง รายงานผลแต่ละข้อ ผ่าน/ไม่ผ่าน พร้อมไฟล์:บรรทัด แล้วแนะนำว่าควรติดตั้งไหม
```

## ตอนติดตั้ง
- **คัดลอกเฉพาะสกิลที่ต้องใช้** ดีกว่าติดตั้งทั้ง plugin ที่อัปเดตตัวเองอัตโนมัติ
- **ตั้งเป็นแบบเรียกเอง (manual-only)** สำหรับสกิลที่ใช้นานๆ ครั้ง: ใส่ `disable-model-invocation: true` สำหรับ Claude และสร้าง `agents/openai.yaml` ที่มี `policy.allow_implicit_invocation: false` สำหรับ Codex
- **ถ้าติดตั้งด้วย `npx skills`** ให้ตั้ง `DO_NOT_TRACK=1` และห้ามติดตั้งชุดเดียวกันทั้งผ่าน `npx skills` และ plugin เพราะสกิลจะซ้ำกัน
- **ตั้งเพิ่มเฉพาะเมื่อจำเป็น** Anthropic แนะนำให้หยุดเพิ่มสกิลเมื่อ agent เริ่มเรียกสกิลที่ถูกต้องได้แย่ลง
- **บันทึก** source และ commit ที่ pin ไว้ลง `setup/skills-lock.md` และสภาพที่ติดตั้งจริงลงหัวข้อ "สภาพเครื่องจริง" ใน `STATE.md` ทุกครั้ง

## ตอนอัปเดต
อ่าน CHANGELOG ของต้นทางก่อนรัน `npx skills update` Anthropic แนะนำให้ถือว่าทุกการอัปเดตคือการติดตั้งใหม่ ต้องตรวจซ้ำ
